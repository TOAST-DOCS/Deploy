<a id="april-14-2026"></a>
### 2026. 04. 14. { #april-14-2026 }
<a id="added-features"></a>
#### 新規機能の追加
* API v2.1 ガイドの新規追加
    * User Access Key トークン (Bearer) 認証方式を適用しました。
* 情報照会 API の追加
    * API v2.0、v2.1 では、アーティファクト一覧照会、サーバーグループ一覧照会、バイナリグループ一覧照会、デプロイ履歴照会、バイナリ一覧照会 API を提供します。
