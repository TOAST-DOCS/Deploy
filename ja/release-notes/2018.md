### 2018. 07. 24. { #july-24-2018 }
<a id="july-24-2018-added-features"></a>
#### 新規機能の追加

* シナリオの Import/Export 機能を追加しました。
* Client Type のメニュー使用制限を解除しました（すべてのメニューが使用可能）。
* サーバーグループの機器区分のための Phase 属性を追加しました。
    * Phase Type が Product であるサーバーのデプロイ時に確認ステップを追加しました。
