### 2021. 07. 27. { #july-27-2021 }
<a id="july-27-2021-feature-updates"></a>
#### 機能改善
* デプロイ履歴照会抽出機能を改善
    * pre-run taskのみ存在するデプロイ履歴も含まれるように修正しました。
* Auto Scaleサービス連携デプロイ失敗時にインスタンス廃棄機能を連動
    * Auto Scaleサービスでスケールアウトの進行中にデプロイに失敗した場合、スケールアウトしたインスタンスを破棄します。
    * 3回以上スケールアウトのデプロイに失敗した場合、スケールアウト機能を停止します。
* セキュリティ脆弱性パッチ

<a id="june-29-2021"></a>
### 2021. 06. 29. { #june-29-2021 }
<a id="june-29-2021-feature-updates"></a>
#### 機能改善
* **デプロイ履歴**タブ検索条件を変更
    * サーバーグループ及び実行日(開始日～終了日)を条件に、デプロイ履歴を検索します。
    * 実行日の検索期間を最大1年に制限しました。
* デプロイ履歴結果をExcelファイルでダウンロードする機能を追加
    * バイナリファイルがない場合は除外してダウンロードできるオプションを追加しました。
