### 2019.02.26 { #february-26-2019 }
<a id="february-26-2019-feature-updates"></a>
#### 機能改善/変更
*編集可能なResourceサイズと内容制限
    *既存：サイズ無制限、すべての編集可能形式のファイル
    *変更：サイズ1MBの制限、unicodeで編集可能な形式のみ編集可能
*タスクTimeout制限時間の増加
    *既存：最大30分
    *変更：最大2時間
