### 2020. 11. 24. { #november-24-2020 }
<a id="november-24-2020-feature-updates"></a>
#### 機能改善
* Auto Scaleサービス連携デプロイ機能を追加(USリージョン除外)
    * Auto Scaleタイプのサーバーグループ作成及びシナリオマッピング機能を提供します。
    * Auto Scaleグループに対するユーザーデプロイ機能を提供します。
* デプロイ実行確認機能を追加
    * デプロイ実行前にデプロイを実行するかどうかを確認します。

<a id="february-25-2020"></a>
### 2020. 02. 25. { #february-25-2020 }
<a id="february-25-2020-feature-updates"></a>
#### 機能改善
* アーティファクト作成時、基本バイナリグループのリージョン設定機能を追加
    * アーティファクト作成時に、バイナリグループのリージョンを指定できるようになりました(KR1/JP1)。
* アーティファクト設定時、基本バイナリグループ指定機能を追加
    * アーティファクト内のバイナリグループの中から選択できます。
<a id="february-25-2020-bug-fixes"></a>
#### バグ修正
* シナリオをアップロードした時、Binary Taskの無効なバイナリグループキー設定の問題を修正
