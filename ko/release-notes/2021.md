### 2021. 07. 27. { #july-27-2021 }
<a id="july-27-2021-feature-updates"></a>
#### 기능 개선
* 배포 이력 조회 추출 기능 개선
    * pre-run task만 존재하는 배포 이력도 포함되도록 수정했습니다.
* Auto Scale 서비스 연계 배포 실패 시 인스턴스 폐기 기능 연동
    * Auto Scale 서비스에서 스케일 아웃을 진행하다 배포에 실패하면 스케일 아웃된 인스턴스를 폐기합니다.
    * 3회 이상 스케일 아웃 배포 실패 시 스케일 아웃 기능을 중지합니다.
* 보안 취약점 패치

<a id="june-29-2021"></a>
### 2021. 06. 29. { #june-29-2021 }
<a id="june-29-2021-feature-updates"></a>
#### 기능 개선
* **배포 이력** 탭 검색 조건 변경
    * 서버 그룹 및 실행일(시작일~종료일) 조건으로 배포 이력을 검색합니다.
    * 실행일 총 검색 기간을 1년으로 제한합니다.
* 배포 이력 결과 Excel 파일로 다운로드 기능 추가
    * 바이너리 파일이 없는 경우 제외하여 다운로드할 수 있는 선택 옵션을 추가했습니다.
