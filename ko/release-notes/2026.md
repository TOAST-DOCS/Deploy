### 2026. 04. 14. { #april-14-2026 }
<a id="added-features"></a>
#### 신규 기능 추가
* API v2.1 가이드 신규 추가
    * User Access Key 토큰(Bearer) 인증 방식을 적용했습니다.
* 정보 조회 API 추가
    * API v2.0, v2.1에서 아티팩트 목록 조회, 서버 그룹 목록 조회, 바이너리 그룹 목록 조회, 배포 이력 조회, 바이너리 목록 조회 API를 제공합니다.
