## Dev Tools > Deploy > Overview

With Deploy, applications can be deployed fast and easy, at 'One Click'. 

* Binary Files 
* Multimedia Files 
* Script Files 
* Execution Files 
* Other Files as User Defines  

![01.png](http://static.toastoven.net/prod_tcdeploy/overview/01.png)

<a id="benefits"></a>

## Benefits { #benefits }

* Easy and convenient binary management
* Simple client binary delivery
    * Email
    * Text message    
* Real-time monitoring by deployment stage
* Deployment result email notifications
* Scenario settings before and after deployment
* Web console support

![02.png](http://static.toastoven.net/prod_tcdeploy/overview/02.png)

<a id="features"></a>

## Main Features { #features }

<a id="upload"></a>

### Upload { #upload }
You can easily upload files using various upload methods.
* Upload Interface
    * Web Console
    * Jenkins Plugin
    * REST API

<a id="download"></a>

### Download { #download }
You can conveniently install and update apps by using the download link notification feature.

<a id="query-binaries"></a>

### Query Binaries { #query-binaries }
You can maintain past binary data to roll back quickly.

<a id="manage-deployment-projects"></a>

### Manage Deployment Projects { #manage-deployment-projects }
You can easily configure infrastructure information by integrating it with your project.

<a id="manage-execute-deployment-scenario"></a>

### Manage Deployment Scenario (Execute) { #manage-execute-deployment-scenario }
You can check the server status after deployment by using custom commands.

<a id="manage-deployment-history"></a>

### Manage Deployment History { #manage-deployment-history }
You can ensure stability by managing deployment details and previous binaries through deployment history.

<a id="glossary"></a>

## Glossary { #glossary }

| Term | Description |
| --- | --- |
| Artifact | Basic unit of the Deploy configuration that manages deployments |
| Server Group | Server group targeted for scenario execution |
| Scenario | Set of tasks to be executed on a server |
| Task | Execution unit of the deployment process |
| Binary | Deployment target file uploaded by the user |
| Resource | Deployment target file that can be created, modified, and managed for history in the web console |
